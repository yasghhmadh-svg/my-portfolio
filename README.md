# 💻 Yassin Hamada - Front-End Developer Portfolio

أهلاً بك في مستودع معرض أعمالي الشخصي! أنا **ياسين حمادة**، مطور واجهات أمامية (Front-End Developer) ومصمم واجهات مستخدم (UI/UX) من مصر. أركز على تحويل الأفكار والتصاميم إلى صفحات ويب حقيقية، سريعة، ومتجاوبة بالكامل.

## 🚀 عن المشروع
هذا المستودع يحتوي على الكود المصدري لموقع معرض أعمالي الشخصي (Portfolio)، والذي أستعرض فيه مهاراتي، الأدوات التي أتقنها، ونماذج من المشاريع التي قمت ببنائها لجذب العملاء على منصات العمل الحر مثل **مستقل**.

## 🛠️ التقنيات المستخدمة
*   **HTML5** - لبناء الهيكل الأساسي للموقع.
*   **CSS3** - للتنسيق والتصميم العصري (مع الاعتماد الكامل على Flexbox و CSS Grid).
*   **JavaScript (ES6+)** - لإضافة الحركات التفاعلية والمنطق البرمجي داخل الصفحات.
*   **Font Awesome** - لأيقونات الموقع.

## 📂 أبرز محتويات الموقع
*   **الرئيسية (Hero Section):** مقدمة تعريفية سريعة.
*   **عني (About Me):** تفاصيل عن شغفي في التطوير وأهدافي كفحريص على رضا العملاء.
*   **نماذج الأعمال (Projects):** واجهات تجريبية مثل متجر الأزياء (nōra)، لوحة تحكم ذكية، وموقع مقهى دافئ.
*   **المهارات (Skills):** الأدوات والتقنيات البرمجية.
*   **تواصل معي (Contact):** استمارة مراسلة مباشرة للمشاريع والاستفسارات.
